# Quem é o Mais Veloz?

O Sonic vai correr até a linha de chegada. Clique no botão "Clique para Correr!" (ou aperte a barra de espaço) repetidamente para o seu personagem avançar mais rápido que ele. Quanto maior a dificuldade, menos tempo o Sonic leva para cruzar a pista!
